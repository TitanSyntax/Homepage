Profil

Kreativität trifft klare Technik.

Meine ersten professionellen Erfahrungen in der Softwareentwicklung sammelte ich während meiner Ausbildung im Web Development.

Meine eigentliche Begeisterung für das Programmieren reicht jedoch weiter. Spieleentwicklung, Modding und aktuell besonders Agentic Engineering gehören zu den Themen, mit denen ich mich intensiv beschäftige.

Mich interessieren moderne Technologien, allerdings nicht um ihrer selbst willen. Software sollte für mich vor allem funktional, schnell und möglichst frei von unnötigem Ballast sein. Deshalb betrachte ich auch etablierte Ökosysteme kritisch und bevorzuge Lösungen, die ein Problem klar und effizient lösen.

Am Programmieren fasziniert mich, dass es selten nur einen richtigen Weg gibt. Die Suche nach einer passenden Lösung erfordert technisches Verständnis und Kreativität. Genau das macht für mich nicht nur das Entwickeln eigener Software, sondern auch das Lesen und Verstehen fremden Codes so interessant.

100 % lokale Verarbeitung
HTML / CSS / JavaScript / XML Live und einsatzbereit

Ein browserbasiertes Werkzeug, das die Bearbeitung von XML Dateien für den Landwirtschafts Simulator 25 vereinfacht.

Statt tief verschachtelte Strukturen und einzelne Reifeneinträge manuell zu durchsuchen, können relevante Attribute gezielt über Suchfilter gefunden und bearbeitet werden. So lassen sich beispielsweise die Traktionswerte aller Reifen übersichtlich anzeigen und schneller anpassen.

Die Datei wird vollständig lokal im Browser verarbeitet. Sie verlässt niemals das Gerät, benötigt keinen Serverspeicher und kann nach der Bearbeitung direkt wieder heruntergeladen werden.
